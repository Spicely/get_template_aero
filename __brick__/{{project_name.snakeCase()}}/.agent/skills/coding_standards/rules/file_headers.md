# 5. File Header Comments

**Rule:** Every Dart file MUST include a standard block comment at the top of the file, providing authorship, summary, and creation date information. 

### Header Template:

```dart
/////////////////////////////////////////////////////////////////////////
///
/// All rights reserved.
///
/// author: Spicely
///
/// Summary: [页面或组件的简要描述]
///
/// Date: [当前日期，例如：2026年05月13日 13:58:04 Wednesday]
///
//////////////////////////////////////////////////////////////////////////
```
