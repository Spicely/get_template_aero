# get_template_aero

[![Powered by Mason](https://img.shields.io/endpoint?url=https%3A%2F%2Ftinyurl.com%2Fmason-badge)](https://github.com/felangel/mason)

使用 Mason CLI 创建的新 Brick 模板。

_Generated by [mason][1] 🧱_

## 快速开始 🚀

> 添加模板

```bash
mason add -g get_template_aero --git-url https://github.com/Spicely/get_template_aero
```

> 初始化项目

```bash
mason make get_template_aero
```

> 插件 in_app_purchase_manager (支付插件)

```bash
mason add -g in_app_purchase_manager --git-url https://github.com/Spicely/get_template_aero.git --git-path packages/in_app_purchase_manager
```

```bash
mason make in_app_purchase_manager
```

> 插件 alipay_manager (支付宝插件)

```bash
mason add -g alipay_manager --git-url https://github.com/Spicely/get_template_aero.git --git-path packages/alipay_manager
```

```bash
mason make alipay_manager
```

> 插件 wx_manager (微信插件)

```bash
mason add -g wx_manager --git-url https://github.com/Spicely/get_template_aero.git --git-path packages/wx_manager
```

```bash

```

## 本地使用 📦

> 添加本地模板

```bash
mason add -g get_template_aero --path .
```

> 从本地模板初始化项目

```bash
mason make get_template_aero
```

> 添加本地插件

```bash
mason add -g in_app_purchase_manager --path packages/in_app_purchase_manager
mason add -g alipay_manager --path packages/alipay_manager
mason add -g wx_manager --path packages/wx_manager
```

> 生成插件代码

```bash
mason make in_app_purchase_manager
mason make alipay_manager
mason make wx_manager
```

## 开发主要流程 🛠️

为了提高调试和开发体验，本项目采用了“参考应用 (Reference App) / 金丝雀”模式。

1. **编辑 (Edit)**: 在 `aero_template_reference` 目录中进行修改。这是一个可以正常运行的 Flutter 项目，你可以使用 IDE 的所有功能（调试、跳转、静态分析等）。
2. **同步 (Sync)**: 开发完成后，运行同步脚本将更改更新回 `__brick__` 模板：
   ```bash
   dart scripts/sync_brick.dart
   ```
3. **发布 (Publish)**: 提交你的更改。`__brick__` 文件夹包含了准备好供 Mason 使用的模板代码。
